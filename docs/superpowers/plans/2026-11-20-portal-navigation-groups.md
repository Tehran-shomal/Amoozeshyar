# گروه‌بندی منوی پورتال دانشجو Implementation Plan

> **For agentic workers:** اجرای مستقیم در همین محیط؛ تغییرات را بر اساس طراحی تأییدشده، گام‌به‌گام انجام بده.

**Goal:** منوی کناری را در پنج گروه کاربردی بچین و وضعیت تحصیلی و مالی را کنار هم در بالای منو قرار بده.

**Architecture:** `NAV_GROUPS` در `apps/core/portal_data.py` مرجع ترتیب و عضویت منو است. فیلد `group` صفحه‌های `PORTAL_PAGES` همان برچسب را برای مسیرنما و بازماندن گروه صفحهٔ فعال نگه می‌دارد؛ قالب و مسیرها نیازی به تغییر ندارند.

**Tech Stack:** Python، Django templates.

**Spec:** `docs/superpowers/specs/2026-11-20-portal-navigation-groups-design.md`

## Global Constraints

- منوی کناری پنج گروه محتوایی داشته باشد؛ داشبورد همچنان پیوند مستقل بالای گروه‌ها باشد.
- عنوان‌ها، متن‌ها، مقادیر نمایشی، مسیر صفحه‌ها، پیوند API و داده‌های نمونه تغییر نکنند.
- هیچ تغییری در دیتابیس، migration یا fixtureهای داده انجام نشود.
- گروه جاری صفحه در مسیرنما/منو با گروه تازه هماهنگ بماند.

## Review Focus

- هر یک از ۳۰ پیوند محتوایی فعلی دقیقاً یک‌بار در یکی از پنج گروه باشد؛ داشبورد پیوند مستقل بماند.
- صفحه‌های فرعی انتخاب درس‌ها و فرم ارزشیابی استاد برچسب گروه تازه را داشته باشند تا مسیرنما و گروه باز با صفحهٔ والد سازگار بمانند.
- نامک هر پیوند ثابت بماند تا URLها و تعاملات API نشکنند.
- پیوند داشبورد و تنظیمات پایین منو دست‌نخورده بمانند.
- هیچ متن یا مقدار نمایشی دیگری در `portal_data.py` ناخواسته تغییر نکند.
